# v2

![Cube Petit v2](/img/cube_petit_v2.png)

Cube Petit v2 is the intermediate model running ROS 1 Noetic. Two variants are available.

---

## Ver2.0 ClearBlue

### Specifications

| Item | Detail |
|---|---|
| Software | ROS 1 Noetic |
| PC | Intel NUC (BLKNUC7I7DNHE / Intel Core i7-8650U) |
| 2D LiDAR | PACECAT LDS-50C |
| IMU | Barometer + 9-axis IMU (Witmotion WT901B) |
| RGB + Depth Camera | Intel RealSense SR305 |
| IR Camera | ELP USBFHD01M-KRL156 |
| Dimensions | W 220 × H 275 × D 220 mm |
| Weight | 7.5 kg |
| Battery | LiFePO4 / 4-cell / 12 V — 3 hrs charge → 3 hrs operation |
| Max Speed | 0.5 m/s |
| Other Modules | MPPT · DC-DC converter · Wi-Fi router (WRH-583GN2-S) |

## What's new in v2 (vs v1)

- **Auto-charging** — Custom LiFePO4 battery with BMS and MPPT
- **Suspension** — Spring hinge suspension for improved wheel clearance
- **Camera upgrade** — RealSense SR305 + IR camera added
- **Processing power** — Upgraded from Raspberry Pi 4 to Intel NUC Core i7 (Ver2.0)
