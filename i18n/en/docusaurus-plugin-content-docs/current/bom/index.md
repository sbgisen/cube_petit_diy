# Bill of Materials (BOM) Overview

A list of all components needed to build Cube Petit.

## Categories

| Category | Description |
|---|---|
| Main Board / PC | The robot's brain |
| Actuators | Motors & servos |
| Sensors | LiDAR, cameras, microphone |
| Power | Battery & power management |
| Structural Parts | Frame & chassis (from CAD) |

For procurement and alternatives, see [Procuring Parts](./procuring-parts).
