# 5. 足回りの組み立て

バネ蝶番サスペンションとモータを取り付けます。

## 必要工具

- 六角レンチ
- 大きなペンチ（ニッパー）

## 使用部品

| 部品 | 数量 |
|---|---|
| バネ蝶番 64mm（ハイロジック） | 4 |
| 蝶番取り付け用 3D プリントパーツ | 4 |
| モータ取り付け用 3D プリントパーツ | 2 |
| DJI RoboMaster M2006 モータ | 2 |
| M4 ステンレスネジ 16mm | 8 |
| M4 黒半ネジ 35mm | 8 |
| M3 黒極低頭ネジ 8mm | 6 |
| M4 ナット | 8 |
| M4 スプリングワッシャー | 8 |
| インシュロック | 4 |

## 手順

### ① モータに 3D パーツを固定

モータに M3 ネジ 3 本でモータ取り付け 3D パーツを固定します。

![足回り 1](/img/assembly/2-5/2-5_underC_107.jpg)
![足回り 2](/img/assembly/2-5/2-5_underC_108.jpg)

### ② バネをカット

4 つの蝶番のうち 2 つのバネのネジをニッパーでカットします。

:::warning
バネを切る際は怪我に注意してください。
:::

![足回り 3](/img/assembly/2-5/2-5_underC_109.jpg)
![足回り 4](/img/assembly/2-5/2-5_underC_110.jpg)

### ③ 蝶番を 3D パーツに取り付け

バネをカットした蝶番を M4 ステンレス＋スプリングワッシャーで 3D パーツに取り付けます（軸が奥向き）。

![足回り 5](/img/assembly/2-5/2-5_underC_111.jpg)
![足回り 6](/img/assembly/2-5/2-5_underC_112.jpg)
![足回り 7](/img/assembly/2-5/2-5_underC_113.jpg)

### ④ ボディへの固定

70mm アルミフレームを左右対称（15.7mm 間隔）に配置します。

金属パーツ 2 枚とインシュロックをバネカット側の蝶番に通し、ボディ後面に M4 黒 35mm ネジで固定します。前面も同様に固定します。

前面の固定順：35mm ネジ → 金属パーツ 2 種 → インシュロック → バネ蝶番 → 3D パーツ

最後にインシュロックを合体させて完成です。
