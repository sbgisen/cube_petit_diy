# 工具

組み立てに必要な工具の一覧です。すでにお持ちの場合は購入不要です。

## 必須工具

| 工具 | 用途 |
|---|---|
| 六角レンチセット（M2.5〜M6） | アルミフレーム・ボルト締め |
| ドライバー＋（#1, #2） | 各種ネジ締め |
| ペンチ | コネクタ・ケーブル作業 |
| ニッパー（小） | ケーブルカット・結束バンド |
| ニッパー（大） | 太いケーブルカット |
| ワイヤーストリッパー | 電線被覆剥き |
| はさみ | テープ・シート切断 |
| ネジ箱 | ネジ・ナット整理 |

## はんだ作業工具

| 工具 | 用途 |
|---|---|
| はんだゴテ（温調付き推奨） | 配線接続 |
| はんだ（鉛フリー推奨） | — |

| ハンダ用マット（耐熱シリコン） | 作業台保護 |
