# v2

![Cube Petit v2](/img/cube_petit_v2.png)

Cube Petit v2 は中間モデルです。ROS 1 Noetic をベースに、自動充電と AI カメラを追加しています。

---

## Ver2.0 ClearBlue

### 仕様

| 項目 | 内容 |
|---|---|
| ソフトウェア | ROS 1 Noetic |
| PC | Intel NUC（BLKNUC7I7DNHE / Intel Core i7-8650U） |
| 2D LiDAR | PACECAT LDS-50C |
| IMU | 気圧計 + 9軸 IMU（Witmotion WT901B） |
| RGB・深度カメラ | Intel RealSense SR305 |
| 赤外線カメラ | ELP USBFHD01M-KRL156 |
| 外形寸法 | 幅 220 × 高さ 275 × 奥行 220 mm |
| 質量 | 7.5 kg |
| バッテリー | LiFePO4 / 4セル / 12 V — 3時間充電で3時間稼働 |
| 移動速度 | 0.5 m/s |
| その他モジュール | MPPT・DC-DC コンバータ・Wi-Fi ルータ（WRH-583GN2-S） |

---

## Ver1.0 Ivory

### 仕様

## v2 の変更点（v1 比）

- **自動充電対応** — 自作 LiFePO4 バッテリー・BMS・MPPT を搭載
- **サスペンション変更** — 足回りのスペース確保のためバネ蝶番式サスペンションに変更
- **カメラ強化** — RealSense SR305 + 赤外線カメラを追加
- **処理能力向上** — Raspberry Pi 4 から Intel NUC（Core i7）へ変更（Ver2.0）
