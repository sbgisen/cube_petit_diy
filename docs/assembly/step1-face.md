# 1. 顔の組み立て

ディスプレイをアクリル板に組み付けます。

## 必要工具

- ニッパー
- 六角レンチ

## 使用部品

| 部品 | 数量 |
|---|---|
| M4 SSHS ネジ 10mm | 2 |
| M4 SSHS ネジ 16mm | 2 |
| M2.5 黒ネジ 6mm | 2 |
| M4 ナット | 6 |
| M2.5 ナット | 2 |
| アクリル板 face1（透明 1mm） | 1 |
| アクリル板 face2（カラー 2mm） | 1 |
| アクリル板 display1（透明 3mm） | 1 |
| アクリル板 display2（透明 3mm） | 1 |

## 手順

### ① ディスプレイの下タブをカット

ディスプレイ下側の 2 つの取り付けタブをニッパーでカットします。

![顔の組み立て 1](/img/assembly/2-1/2-1_face_178.jpg)

### ② ディスプレイに透明アクリルを固定

透明アクリル板（display1）をディスプレイに重ね、M2.5 ネジ 2 本で固定します。

![顔の組み立て 2](/img/assembly/2-1/2-1_face_179.jpg)

### ③ アクリル板を重ねてナット止め

裏返して、透明 1mm 板（face1）→ カラー板（face2）→ ディスプレイの順に重ね、M4 ネジ（10mm・16mm）でナット止めします。

![顔の組み立て 3](/img/assembly/2-1/2-1_face_180.jpg)
![顔の組み立て 4](/img/assembly/2-1/2-1_face_181.jpg)

### ④ 長細いアクリルを追加

display2（長細い透明板）を追加してナット止めします。

![顔の組み立て 5](/img/assembly/2-1/2-1_face_182.jpg)

### ⑤ 完成

表に返して完成です。

![顔の組み立て 完成](/img/assembly/2-1/2-1_face_183.jpg)
