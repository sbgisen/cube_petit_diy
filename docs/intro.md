# Cube Petit DIY へようこそ

**Cube Petit**（キューブプチ）は、ROS 2 に対応した小型の自律走行ロボットキットです。
このドキュメントでは、Cube Petit を自分で組み立てるための部品・手順・ソフトウェアセットアップをまとめています。

> 小さな体で、走って、聞いて、話して、表情を出す。

## ハードウェアバージョンを選ぶ

Cube Petit にはハードウェアバージョンがあります。
最新のバージョンを選ぶことを推奨します。

| バージョン | 概要 |
|---|---|
| [v3（最新）](./versions/v3) | 現行モデル。ROS2 Humble/Jazzy 対応 |
| [v2](./versions/v2) | 中間モデル。ROS1 Noetic / PC / 自動充電対応型 |
| [v1](./versions/v1) | 初代モデル。ROS1 Melodic / RaspberriPy5 |

:::tip
 **v3** を参照してください。
:::
