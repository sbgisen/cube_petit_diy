# 2. アルミフレームの組み立て

ボディの骨格となるアルミフレームを組み立てます。

## 必要工具

- 六角レンチ

## 使用部品

| 部品 | 数量 |
|---|---|
| アルミフレーム A〜Z | 26本 |
| 三角ブラケット | 30 |
| 四角ブラケット | 4 |
| 丸型ブラケット | 8 |
| M4 黒ネジ 10mm | 74 |
| M4 ステンレスネジ 8mm | 8 |
| M4 四角ナット | 106 |
| ナットホルダー | 106 |
| L字ブラケット（金属板） | 2 |
| T字ブラケット（金属板） | 2 |
| L字ブラケット（Misumi） | 2 |

## 手順

### ① ナットホルダーの取り付け

フレーム A〜Z に、ナットホルダーと M4 ナットを取り付けます（合計 106 個）。

![アルミフレーム 1](/img/assembly/2-2/2-2_almi_frame_080.jpg)
![アルミフレーム 2](/img/assembly/2-2/2-2_almi_frame_081.jpg)

### ② 天板の作成

フレーム A・B・C・D・E・F を、三角ブラケット・丸形ブラケット・T字ブラケットで接続して天板を作ります。

![アルミフレーム 3](/img/assembly/2-2/2-2_almi_frame_082.jpg)
![アルミフレーム 4](/img/assembly/2-2/2-2_almi_frame_083.jpg)
![アルミフレーム 5](/img/assembly/2-2/2-2_almi_frame_084.jpg)

### ③ 天板つなぎフレーム

フレーム G・H を T字ブラケットで E・F の前後に接続します。

:::note
センサ類を取り付けた後に、天板とボディを合体させます。
:::

![アルミフレーム 6](/img/assembly/2-2/2-2_almi_frame_085.jpg)
![アルミフレーム 7](/img/assembly/2-2/2-2_almi_frame_086.jpg)

### ④ 上面の作成

フレーム I・J・K・L・M・N に L字ブラケット・L字金属板・丸形ブラケットを使って上面を組み立てます。

![アルミフレーム 8](/img/assembly/2-2/2-2_almi_frame_087.jpg)
![アルミフレーム 9](/img/assembly/2-2/2-2_almi_frame_088.jpg)
![アルミフレーム 10](/img/assembly/2-2/2-2_almi_frame_089.jpg)
![アルミフレーム 11](/img/assembly/2-2/2-2_almi_frame_090.jpg)

### ⑤ 底面の作成

フレーム S・T・U・V・W・X・Y・Z を三角ブラケットで接続します。70mm フレームを左右対称に配置します。

![アルミフレーム 12](/img/assembly/2-2/2-2_almi_frame_092.jpg)
![アルミフレーム 13](/img/assembly/2-2/2-2_almi_frame_093.jpg)
![アルミフレーム 14](/img/assembly/2-2/2-2_almi_frame_094.jpg)
![アルミフレーム 15](/img/assembly/2-2/2-2_almi_frame_095.jpg)
![アルミフレーム 16](/img/assembly/2-2/2-2_almi_frame_096.jpg)

### ⑥ 上面と底面の接続

フレーム O・P・Q・R（150mm）で上面と底面を接続します。S フレームを四角ブラケット（穴が外装側）で固定し、ステンレスネジを通します。

![アルミフレーム 17](/img/assembly/2-2/2-2_almi_frame_097.jpg)
![アルミフレーム 18](/img/assembly/2-2/2-2_almi_frame_098.jpg)
![アルミフレーム 19](/img/assembly/2-2/2-2_almi_frame_099.jpg)
![アルミフレーム 20](/img/assembly/2-2/2-2_almi_frame_100.jpg)
![アルミフレーム 21](/img/assembly/2-2/2-2_almi_frame_101.jpg)
![アルミフレーム 22](/img/assembly/2-2/2-2_almi_frame_102.jpg)
![アルミフレーム 23](/img/assembly/2-2/2-2_almi_frame_103.jpg)

:::tip
センサ取り付け後に天板とボディを合体させ、ネジをしっかり締めます。
:::
