# Welcome to Cube Petit DIY

**Cube Petit** is a compact ROS 2 autonomous robot kit.
This documentation covers the parts, assembly steps, and software setup needed to build your own Cube Petit.

> Small body — move, listen, talk, and express.

## Choose your hardware version

Cube Petit has multiple hardware generations. Select your version below.

| Version | Description |
|---|---|
| [v3 (Latest)](./versions/v3) | Current model. ROS 2 support, expression panel |
| [v2](./versions/v2) | Intermediate model |
| [v1](./versions/v1) | Original model |

:::tip
If you're not sure which version you have, refer to **v3**.
:::
