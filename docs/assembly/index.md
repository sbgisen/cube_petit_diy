# 組み立て手順 概要

Cube Petit の組み立ては以下の順番で進めます。

:::tip 事前確認
組み立て前に [部品リスト](/bom/) で全部品が揃っていることを確認してください。
:::

## 組み立てステップ

| ステップ | 内容 |
|---|---|
| [1. 顔](./step1-face) | ディスプレイをアクリル板に組み付ける |
| [2. アルミフレーム](./step2-frame) | ボディ骨格を組み立てる |
| [3. キャスター](./step3-caster) | アルミフレームにキャスターを取り付ける |
| [4. タイヤ](./step4-tire) | タイヤを組み立てる |
| [5. 足回り](./step5-undercarriage) | バネ蝶番サスペンションとモータを取り付ける |
| [6. モーターコントローラ配線](./step6-motor) | CAN配線・電源配線・ID設定 |
| [7. センサ](./step7-sensor) | LiDAR・深度カメラ・AIカメラを取り付ける |
| [8. スピーカ](./step8-speaker) | スピーカの配線と取り付け |
