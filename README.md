# CubePetit DIY

**CubePetit DIY** provides parts lists, assembly guides, and hardware resources for building CubePetit, a compact ROS 2 mobile robot kit.

CubePetit is a small mobile robot platform designed for learning, prototyping, exhibitions, and interactive robot development.

> CubePetitを自分で作ってみたい人のための、部品・組み立て・ハードウェア情報をまとめるリポジトリです。

## Start here

- **Parts List**: 必要な部品・購入先・代替部品
- **Assembly Guide**: 組み立て手順
- **Wiring Guide**: 配線・電源まわり
- **Hardware Notes**: 設計上の注意点・調整方法
- **CAD Data**: 筐体や部品データへのリンク
- **ROS 2 Software**: CubePetitを動かすROS 2パッケージへのリンク
