# 4. タイヤの組み立て

ホイール・タイヤ・インナースポンジを組み合わせてタイヤを作ります。

## 必要工具

- 瞬間接着剤

## 使用部品

| 部品 | 数量 |
|---|---|
| ホイール（TAMIYA OP-471） | 2 |
| タイヤ（TAMIYA OP.1952） | 2 |
| インナースポンジ（TAMIYA OP-156） | 2 |

## 手順

### ① インナースポンジをタイヤにはめる

![タイヤ 1](/img/assembly/2-4/2-4_tiya01.jpg)

### ② ホイールをタイヤにはめる

![タイヤ 2](/img/assembly/2-4/2-4_tiya02.jpg)

### ③ 瞬間接着剤を流す

ホイールとタイヤの隙間に瞬間接着剤を流して固定します。

![タイヤ 3](/img/assembly/2-4/2-4_tiya03.jpg)

:::note
タイヤの取り付けはモーターコントローラの ID 設定（ステップ 6）後に行います。
:::
