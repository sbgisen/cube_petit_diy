Cube Petit v3 組み立て手順（全ページ）

1. 顔の組み立て

ディスプレイをアクリル板に組み付けます。

必要工具​

  • ニッパー
  • 六角レンチ

使用部品​

部品数量
M4 SSHS ネジ 10mm2
M4 SSHS ネジ 16mm2
M2.5 黒ネジ 6mm2
M4 ナット6
M2.5 ナット2
アクリル板 face1（透明 1mm）1
アクリル板 face2（カラー 2mm）1
アクリル板 display1（透明 3mm）1
アクリル板 display2（透明 3mm）1

手順​

① ディスプレイの下タブをカット​

ディスプレイ下側の 2 つの取り付けタブをニッパーでカットします。

② ディスプレイに透明アクリルを固定​

透明アクリル板（display1）をディスプレイに重ね、M2.5 ネジ 2 本で固定します。

③ アクリル板を重ねてナット止め​

裏返して、透明 1mm 板（face1）→ カラー板（face2）→ ディスプレイの順に重ね、M4 ネジ（10mm・16mm）でナット止めします。

④ 長細いアクリルを追加​

display2（長細い透明板）を追加してナット止めします。

⑤ 完成​

表に返して完成です。

2. アルミフレームの組み立て

ボディの骨格となるアルミフレームを組み立てます。

必要工具​

  • 六角レンチ

使用部品​

部品数量
アルミフレーム A〜Z26本
三角ブラケット30
四角ブラケット4
丸型ブラケット8
M4 黒ネジ 10mm74
M4 ステンレスネジ 8mm8
M4 四角ナット106
ナットホルダー106
L字ブラケット（金属板）2
T字ブラケット（金属板）2
L字ブラケット（Misumi）2

手順​

① ナットホルダーの取り付け​

フレーム A〜Z に、ナットホルダーと M4 ナットを取り付けます（合計 106 個）。

② 天板の作成​

フレーム A・B・C・D・E・F を、三角ブラケット・丸形ブラケット・T字ブラケットで接続して天板を作ります。

③ 天板つなぎフレーム​

フレーム G・H を T字ブラケットで E・F の前後に接続します。

注記

センサ類を取り付けた後に、天板とボディを合体させます。

④ 上面の作成​

フレーム I・J・K・L・M・N に L字ブラケット・L字金属板・丸形ブラケットを使って上面を組み立てます。

⑤ 底面の作成​

フレーム S・T・U・V・W・X・Y・Z を三角ブラケットで接続します。70mm フレームを左右対称に配置します。

⑥ 上面と底面の接続​

フレーム O・P・Q・R（150mm）で上面と底面を接続します。S フレームを四角ブラケット（穴が外装側）で固定し、ステンレスネジを通します。

ヒント

センサ取り付け後に天板とボディを合体させ、ネジをしっかり締めます。

3. キャスターの取り付け

アルミフレームの底面にキャスターを取り付けます。

必要工具​

  • 六角レンチ

使用部品​

部品数量
キャスター4
M4 黒極低頭ネジ 10mm12
M4 ワッシャー12
M4 スプリングワッシャー12

手順​

① キャスターの固定​

スプリングワッシャー → ワッシャーの順で低頭ネジに通し、キャスターの向きに注意して 3 点ずつ固定します。

4. タイヤの組み立て

ホイール・タイヤ・インナースポンジを組み合わせてタイヤを作ります。

必要工具​

  • 瞬間接着剤

使用部品​

部品数量
ホイール（TAMIYA OP-471）2
タイヤ（TAMIYA OP.1952）2
インナースポンジ（TAMIYA OP-156）2

手順​

① インナースポンジをタイヤにはめる​

② ホイールをタイヤにはめる​

③ 瞬間接着剤を流す​

ホイールとタイヤの隙間に瞬間接着剤を流して固定します。

注記

タイヤの取り付けはモーターコントローラの ID 設定（ステップ 6）後に行います。

5. 足回りの組み立て

バネ蝶番サスペンションとモータを取り付けます。

必要工具​

  • 六角レンチ
  • 大きなペンチ（ニッパー）

使用部品​

部品数量
バネ蝶番 64mm（ハイロジック）4
蝶番取り付け用 3D プリントパーツ4
モータ取り付け用 3D プリントパーツ2
DJI RoboMaster M2006 モータ2
M4 ステンレスネジ 16mm8
M4 黒半ネジ 35mm8
M3 黒極低頭ネジ 8mm6
M4 ナット8
M4 スプリングワッシャー8
インシュロック4

手順​

① モータに 3D パーツを固定​

モータに M3 ネジ 3 本でモータ取り付け 3D パーツを固定します。

② バネをカット​

4 つの蝶番のうち 2 つのバネのネジをニッパーでカットします。

危険

バネを切る際は怪我に注意してください。

③ 蝶番を 3D パーツに取り付け​

バネをカットした蝶番を M4 ステンレス＋スプリングワッシャーで 3D パーツに取り付けます（軸が奥向き）。

④ ボディへの固定​

70mm アルミフレームを左右対称（15.7mm 間隔）に配置します。

金属パーツ 2 枚とインシュロックをバネカット側の蝶番に通し、ボディ後面に M4 黒 35mm ネジで固定します。前面も同様に固定します。

前面の固定順：35mm ネジ → 金属パーツ 2 種 → インシュロック → バネ蝶番 → 3D パーツ

最後にインシュロックを合体させて完成です。

注記

タイヤの取り付けはモーターコントローラの ID 設定（ステップ 6）後に行います。

6. モーターコントローラの配線

CAN 配線・電源配線を行い、モータ ID を設定します。

必要工具​

  • はんだごて・はんだ
  • ニッパー
  • ワイヤーストリッパー
  • ヒートガン
  • テスター

使用部品​

部品数量
CANable Pro1
Molex 3.25mm ピッチ 3pin（基板 L型）1
Molex 3.25mm ピッチ 3pin（ソケット）1
5pin SM コネクタ（ソケット）1
5pin SM コネクタ（コネクタ）1
DC 電源コネクタ（内径 2.5mm）1
DJI RoboMaster C610 モータコントローラ2
透明熱収縮チューブ Φ21適量
赤・黒熱収縮チューブ Φ6各適量
赤・緑・黒 ケーブル AWG20各 1 本
リボンケーブル適量

手順​

① ケーブルの準備​

  • 赤・黒・緑ケーブルを 120mm にカット
  • リボンケーブル 3 芯を 120mm × 2 本にカット
  • 透明熱収縮 50mm、赤黒熱収縮 30mm にカット

② CANable Pro のコネクタ交換​

CANable Pro のバージョンを確認します（Ver1.0 は TERM にジャンパ切替が必要）。

3pin コネクタを外し Molex に交換します。ピン順：CANL・CANH・GND

③ SM コネクタの作成​

SM コネクタを作成します。ピン順：

ピン信号色
1GND黒
2CANL緑
3CANH赤

ワイヤーストリッパーで被膜を剥いてはんだ付けします。

④ 電源ケーブルの作成​

電源ケーブル 120mm でカットします。C610 付属電源ケーブル 2 本 + カットケーブル 1 本の赤・黒各 3 本をまとめてはんだ付け → 熱収縮 → DC ジャックにはんだ付けします。

⑤ C610 への CAN 配線​

C610 の CANL・CANH・GND にリボンケーブルをはんだ付けし、SM コネクタで接続します。

ピン信号
1GND
2CANL
3CANH

⑥ 導通確認・熱収縮​

テスターで導通を確認します。問題なければ CANable Pro に Φ21 熱収縮、C610 に付属熱収縮チューブを装着します。

⑦ 電源テスト・ID 設定​

モバイルバッテリー（12V 出力）に接続して電源テストします。赤以外の LED が点滅すれば成功です。

次にモータ ID を設定します。C610 の黒ボタンを押す回数で ID を設定します：

モータIDボタン押し回数
左モータ11 回
右モータ22 回

設定完了後、インシュロックでボディに固定します。タイヤを取り付けます。

7. センサの取り付け

LiDAR・深度カメラ・AI カメラをアルミフレームに取り付けます。

必要工具​

  • 六角レンチ
  • ヒートガン

使用部品​

部品数量
2D LiDAR（LDROBOT LD19） + 取り付け金属部材1
AI カメラ（OAK-1） + 3D プリントマウント1
深度カメラ（Intel RealSense D435i） + 3D プリントマウント1
透明熱収縮チューブ Φ21 40mm1
M2.5 黒ネジ 5mm3
M4 黒ネジ 10mm8
M6 ステンレスネジ 8mm（深度カメラ用）1
M6 黒ネジ 5mm（AI カメラ用）1
M2.5 ナット3
注記

AI カメラ・深度カメラの取り付けは本来 1/4 インチネジですが、M6 で代用します。

手順​

① 各センサに 3D パーツを取り付け​

  • 深度カメラ：M6 ステンレスネジで 3D プリントパーツを取り付け
  • AI カメラ：M6 黒ネジで 3D プリントパーツを取り付け
  • LiDAR：M2.5 ネジ 3 本＋ナットで金属部材に取り付け

② 本体への取り付け順​

以下の順でボディに取り付けます：

  1. 前面 — 深度カメラ（RealSense D435i）
  2. 上部 — LiDAR（小さな丸が前面・真ん中）
  3. 前面 — AI カメラ（OAK-1）

③ LiDAR の熱収縮​

40mm 熱収縮チューブを LiDAR 基板に装着してヒートガンで収縮させます。

センサ取り付け完了後、天板とボディを合体させてネジを固く締めます。

8. スピーカの取り付け

スピーカの配線と取り付けを行います。

必要工具​

  • はんだごて・はんだ
  • ワイヤーストリッパー
  • 圧着工具
  • ニッパー

使用部品​

部品数量
フルレンジスピーカー 40mm 4Ω 10W2
USB 給電デジタルアンプ（NFJ）1
SM コネクタ 2pin セット2

手順​

① アンプケーブルの加工​

アンプのケーブルを半分にカットし、SM コネクタを取り付けます。

残りのケーブルで 2 本作成します：

  • 1 本：スピーカにはんだ付け
  • 1 本：SM コネクタを取り付け（黒が 1 番）

② スピーカへのはんだ付け​

スピーカにケーブルをはんだ付けします。

極性色
＋（プラス）赤または白
−（マイナス）黒

③ 本体への取り付け​

L字ブラケットに引っ掛けて取り付けます。天板取り付け後に位置を調整してネジを固く締めます。

これで組み立ては完了です。次は PC 設定・USB 配線 へ進みます。

組み立て完了。次は PC 設定・USB 配線 へ進んでください。
