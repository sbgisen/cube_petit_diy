# v3（最新モデル）

Cube Petit v3 は現行モデルです。
ROS 2 (Humble/Jazzy)に対応し、LLMを用いた会話機能・デモを搭載しています。

## 仕様

| 項目 | 内容 |
|---|---|
| ソフトウェア | ROS 2 Humble/Jazzy |
| メイン PC | MINISFORUM UM690L Slim |
| 深度カメラ | Intel RealSense D435i |
| 2D LiDAR | LD19 |
| AI カメラ | OAK-1 |

## v3 の変更点

工場生産のため安全性の高いモバイルバッテリーに変更しました
