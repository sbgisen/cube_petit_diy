# 7. センサの取り付け

LiDAR・深度カメラ・AI カメラをアルミフレームに取り付けます。

## 必要工具

- 六角レンチ
- ヒートガン

## 使用部品

| 部品 | 数量 |
|---|---|
| 2D LiDAR（LDROBOT LD19） + 取り付け金属部材 | 1 |
| AI カメラ（OAK-1） + 3D プリントマウント | 1 |
| 深度カメラ（Intel RealSense D435i） + 3D プリントマウント | 1 |
| 透明熱収縮チューブ Φ21 40mm | 1 |
| M2.5 黒ネジ 5mm | 3 |
| M4 黒ネジ 10mm | 8 |
| M6 ステンレスネジ 8mm（深度カメラ用） | 1 |
| M6 黒ネジ 5mm（AI カメラ用） | 1 |
| M2.5 ナット | 3 |

:::note
AI カメラ・深度カメラの取り付けは本来 1/4 インチネジですが、M6 で代用します。
:::

## 手順

### ① 各センサに 3D パーツを取り付け

- 深度カメラ：M6 ステンレスネジで 3D プリントパーツを取り付け
- AI カメラ：M6 黒ネジで 3D プリントパーツを取り付け
- LiDAR：M2.5 ネジ 3 本＋ナットで金属部材に取り付け

![センサ 1](/img/assembly/2-7/2-7_sensor_000.jpg)
![センサ 2](/img/assembly/2-7/2-7_sensor_161.jpg)

### ② 本体への取り付け順

以下の順でボディに取り付けます：

1. **前面** — 深度カメラ（RealSense D435i）
2. **上部** — LiDAR（小さな丸が前面・真ん中）
3. **前面** — AI カメラ（OAK-1）

### ③ LiDAR の熱収縮

40mm 熱収縮チューブを LiDAR 基板に装着してヒートガンで収縮させます。

![センサ 10](/img/assembly/2-7/2-7_sensor_169.jpg)
![センサ 11](/img/assembly/2-7/2-7_sensor_170.jpg)

センサ取り付け完了後、天板とボディを合体させてネジを固く締めます。
