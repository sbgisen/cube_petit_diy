# 3. キャスターの取り付け

アルミフレームの底面にキャスターを取り付けます。

## 必要工具

- 六角レンチ

## 使用部品

| 部品 | 数量 |
|---|---|
| キャスター | 4 |
| M4 黒極低頭ネジ 10mm | 12 |
| M4 ワッシャー | 12 |
| M4 スプリングワッシャー | 12 |

## 手順

### ① キャスターの固定

スプリングワッシャー → ワッシャーの順で低頭ネジに通し、キャスターの向きに注意して 3 点ずつ固定します。
